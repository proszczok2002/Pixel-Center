# Polityka prywatności / Privacy Policy

Ostatnia aktualizacja / Last updated: 2026-10-31

## Polski

Pixel Center działa lokalnie na urządzeniu. Aplikacja nie zawiera reklam, analityki ani telemetrii i nie przesyła deweloperowi treści ekranu, naciśnięć przycisków, odsłuchiwanych materiałów ani danych osobowych.

Usługa ułatwień dostępu jest używana wyłącznie do realizacji włączonych przez użytkownika funkcji, w szczególności obsługi ekranu ostatnich aplikacji i sterowania przyciskami. Dostęp do powiadomień lub sesji multimedialnych służy do rozpoznawania aktywnego odtwarzacza i wysyłania poleceń multimedialnych. Przetwarzanie odbywa się lokalnie.

Po ręcznym sprawdzeniu aktualizacji aplikacja łączy się z `raw.githubusercontent.com`, a podczas pobierania wydania z `github.com` i hostami przekierowań używanymi przez GitHub. GitHub może przetwarzać standardowe dane połączenia, takie jak adres IP, zgodnie z własną polityką prywatności. Kliknięcie linku Revolut lub PayPal otwiera zewnętrzną aplikację albo przeglądarkę; dalsze przetwarzanie danych podlega zasadom danego usługodawcy.

## English

Pixel Center operates locally on the device. It contains no advertising, analytics, or telemetry and does not send the developer screen contents, button presses, played media, or personal data.

The accessibility service is used only to provide features enabled by the user, particularly recent-apps handling and button controls. Notification or media-session access is used to identify the active player and send media commands. Processing is local.

When the user checks for updates, the app connects to `raw.githubusercontent.com` and, while downloading a release, to `github.com` and redirect hosts used by GitHub. GitHub may process normal connection data such as an IP address under its own privacy policy. Opening a Revolut or PayPal link launches an external app or browser; subsequent processing is governed by that provider.
